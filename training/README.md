# KIS Training Engine

Prototype training engine design branch. The HTML proof of concept is distributed separately pending review of the navigation and lesson structure.

Course organization:
- 01 Academic learning: expandable chapter lessons
- 02 Playbooks: guided step-by-step interactive flows
- 03 Calculators: independent tools with associated academic notes
- 04 Knowledge checks: domain-based questions

Engine navigation and interaction components remain distinct from canonical knowledgebase and playbook sources.
