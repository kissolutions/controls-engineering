# As-found review pattern (P5)

During M1/M2 site surveys, preserve the distinction between **observed label or photo evidence**, **confidence of the read**, **engineering interpretation**, and **action for verification**. A photograph is source evidence; a transcription is a candidate fact until legibility and device identity are verified.

| Field | Record |
|---|---|
| Evidence ID | Source file, drawing/photo identifier, timestamp, location if permitted in private project storage |
| Observed | Exact visible label, terminal, breaker, part/model, LED, wire color or configuration as read; quote it as observed |
| Read confidence | High / Medium / Low, with visible obstruction/blur explicitly documented |
| Interpretation | What it may imply; do not elevate it to manufacturer specification or confirmed wiring |
| Action | Field follow-up, vendor source, open Issue/RFI and acceptance owner |
| Affected IDs | Equipment, device, point, panel, Scope, Work Package and source IDs where known |

**Do not** assert a contact, module, firmware or signal is available because a display or photo suggests it. Do not publish identifying site photographs or equipment serials to the framework. Cross-check any safety-critical wiring with onsite identification and manufacturer instructions.
