# Klutch Controls Standards Profile — v0.1 (draft)

Klutch Controls' engineering standards for controls deliverables, layered on the KIS controls-engineering framework. Precedence and override rules: [Organization Standards Profiles](../README.md).

Klutch builds deliverables on one repeated motif so that content is copy/paste between projects and every set reads the same way. This profile writes that motif down. When Klutch updates a major standard, update the page and bump the version in [CHANGELOG](CHANGELOG.md).

|---|---|---|

| [Naming](naming.md) | Device tags vs signal names; panel, controller, point, SCADA and object names | draft |
| [Narrative format](narrative-format.md) | Controls narrative layout and required content | draft |
