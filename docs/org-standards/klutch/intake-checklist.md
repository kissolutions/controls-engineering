# Klutch Project Intake Checklist

Questions to settle at project intake, before design. Look for the answer in the proposal, the vendor submittals and the client's documents first; raise an Issue only when the answer is not already there.

| Item | Applies to | Rule |
|---|---|---|
| Door switches | Every air handler | AHUs have access doors. Reserve a DOOR-SW input (on the safety relay) until it is confirmed that no door switches exist. If intake answers the question immediately, no reservation is needed. |
| Owner point naming standard | Every project | Register it as a source (see [Naming](naming.md)). |
| Owner standards and unwritten expectations | Every project | Check the client conventions pages (for example [UTMB](client-conventions/utmb.md)). |

*(Further intake items to be added from project experience.)*

## Reserved safety inputs

A reserved safety input that has no device yet is jumpered so the system can run. The jumper is shown on the drawings and recorded as an open item until the device is installed or confirmed not to exist.
